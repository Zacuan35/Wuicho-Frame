Buttons

Botones para acciones primarias, secundarias y de estado, en distintos tamaños, variantes y formatos (con ícono, circulares, agrupados).

Botones predeterminados

Variantes de énfasis para las acciones más comunes: primary para la acción principal, secondary y outline para acciones secundarias, ghost para bajo énfasis, y su estado deshabilitado.

<button class="btn btn-primary">Primary</button>
<button class="btn btn-outline">Outline</button>
<button class="btn btn-ghost">Ghost</button>
Botones de estado

Success, warning y danger comunican el resultado de una acción: confirmación, advertencia o error.

Tamaños de botones

sm · base · lg — mismo componente, distinta densidad.

Botón de bloque

btn-block hace que el botón ocupe todo el ancho disponible de su contenedor, útil en formularios o layouts angostos.

Con ícono

Un ícono antes del texto ayuda a reconocer la acción más rápido; hereda el color del botón automáticamente.

Botones circulares

Solo ícono, sin texto: para acciones compactas y repetidas, como editar o eliminar en una fila de tabla.

Botón de grupo

Dos botones unidos visualmente como una sola unidad, para acciones relacionadas o mutuamente excluyentes.

Social links

Enlaces circulares a redes sociales; al pasar el cursor toman el color de marca de cada plataforma.
